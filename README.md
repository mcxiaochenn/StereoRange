# StereoRange

基于双目视觉视差原理的任意表面测距系统，计划使用 Python 实现。

## 项目简介

StereoRange 旨在通过双目相机获取同一场景的左右视图，利用对应点之间的视差估算深度，从而实现对任意表面的非接触式距离测量。

对于完成标定并校正后的平行双目相机，目标深度可由下式估算：

```text
Z = fB / d
```

其中：

- `Z`：目标点到相机的深度；
- `f`：相机焦距；
- `B`：左右相机光心之间的基线距离；
- `d`：同一目标点在左右图像中的视差。

## 预期功能

- 双目相机标定与图像校正；
- 左右图像采集与同步；
- 视差图计算与优化；
- 深度计算和三维点云生成；
- 任意表面的距离查询与结果可视化；
- 标定参数及测距结果的保存与读取。

## 计划技术栈

- Python
- OpenCV
- NumPy

## 基本流程

1. 采集双目标定图像并计算相机内参、畸变参数及双目外参。
2. 对左右图像进行立体校正，使对应点位于同一水平线上。
3. 进行立体匹配并生成视差图。
4. 根据焦距、基线与视差计算深度。
5. 对测距结果进行可视化，并按需生成三维点云。
