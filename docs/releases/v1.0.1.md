# StereoRange v1.0.1

Flutter + Rust 安卓版首次正式签名发布，最低 Android 13，ARM64。

## 本版内容

- Material 3 中文测距、设备、设置三页面，支持横竖屏和明暗主题。
- USB OTG 双目相机、每侧 320×240、OpenCV 校正/SGBM、YOLOX-Nano 离线识别。
- 最近/中心/最远三点、全场景/仅识别物体模式、点击测距、标定 JSON 导入、截图与演示。
- 设置页新增 GitHub 仓库卡片，点击打开浏览器；补齐原生依赖许可。
- 电脑端新增 NPZ → Android JSON 标定导出，保留 Python 桌面功能。
- 上传 3D 打印底座、公差测试模型及相应 PRT/STL 文件。

## 下载与安装

正式下载：https://github.com/mcxiaochenn/StereoRange/releases/tag/v1.0.1

- `StereoRange-v1.0.1-android-arm64.apk`
  - SHA-256：`4ee07c685cc1d274f913f4dc16f6322ef3b24502d1cf8a7263b7c9a657e25e19`
  - ABI：仅 `arm64-v8a`；`versionName=1.0.1`，`versionCode=101`，`minSdk=33`
  - 签名证书 SHA-256：`0d348f24c796ae569029cb3e37b4a9aad1024c6ad8697778cc66e05337000622`
- `StereoRange-v1.0.1-3d-print.zip`：`assets/3d-print/` 模型打包
- `SHA256SUMS.txt`：校验上述文件

公开包仅内置官方识别模型，不含个人标定或拍摄图片。真实测距需导入本相机匹配的标定；无标定仍可预览、识别和运行模拟演示。

应用设置页含「GitHub 项目仓库」卡片，点击将调用系统浏览器打开本仓库。

旧调试版不能直接覆盖安装，因为签名不同。请保留标定文件后自行卸载调试版，再安装正式版。后续正式版本使用同一长期签名升级。

3D 文件同时保存在仓库 `assets/3d-print/`，可下载 Release 中的模型压缩包。论文草稿见 `assets/papers/`。

## 验证与限制

Python 47 项、Rust 8 项、Flutter 7 项测试通过，静态分析无问题。此前调试构建在小米 17 Pro / Android 17 上完成真实相机与 UI 集成验证：30 秒约 30 FPS 深度处理，识别采样约 10 FPS。

正式构建单独验证签名、版本号、16 KB 原生库/ZIP 对齐和 APK 资源内容。已知物距误差与连续运行压测已在本项目中完成验收；更换设备或分辨率后需重新标定并按现场条件复核。
