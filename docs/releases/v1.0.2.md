# StereoRange v1.0.2

Flutter + Rust 安卓端正式签名发布。**Release tag 为 `vX.Y.Z`**；APK 文件名中的 `+N` 由 CI 自动附加 git 提交次数。

## 本版内容

- Material 3 中文测距、设备、设置三页面；USB OTG 双目相机、OpenCV 校正/SGBM、YOLOX-Nano 离线识别。
- 最近/中心/最远三点、全场景/仅识别物体、点击测距、标定 JSON 导入、截图与演示。
- 设置页 GitHub 仓库卡片；桌面端 `calibrate.py export-mobile` 导出安卓标定。
- 3D 打印模型与论文草稿归档至 `assets/`。
- 作者署名区分：陆逸尘（辰渊尘 ChenDusk / @mcxiaochenn）、周璟雯、胡乐毅、指导教师 张梁。
- CI 工作流 `build-apk`：push main 出 Actions 产物；tag `vX.Y.Z` 自动签名构建并挂 Release。
