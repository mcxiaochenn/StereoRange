# 2026-09-19 历史进展补录（Codex 会话） **[重大]**

> 本文补录自 ChatGPT/Codex 共享会话「完善双目测距项目说明」的时间线，便于 Agent 快速对齐项目已走到哪一步。

## 阶段时间线

1. **建仓与 README**：公开仓库 `mcxiaochenn/StereoRange` 建立，About 与主题标签就绪。
2. **桌面基础版**：无相机/无标定也能跑的模拟双目演示；`Z=fB/d`、SGBM、7×7 点击测距、输出 npy/png/json。
3. **实时相机**：默认索引 0，横向拼接 `640×240` 拆左右；标定参数先用占位值（`700 px` / `0.12 m`）。
4. **标定链路**：A4 棋盘 PDF/SVG、采集、双目标定、运行时 `remap` 校正接入。
5. **私有数据子模块**：`private-data/` 保存标定与实拍图；公开仓库只暴露指针。
6. **比赛 UI**：PySide6 单窗口 + YOLOX-Nano + 三点测距 + 全场景/物体模式 + `启动测距.bat`。
7. **作者署名**：UI/CLI/pyproject/README 统一署名。
8. **论文框架**：系统设计与实现类论文大纲已给出（标题、章节、实验表）。
9. **分辨率实验**：试过最高 `3840×1080`（SGBM 约 0.65 s/帧）；实测跑满约 30 FPS 的组合是每侧 `320×240`。**已改回 640×240。**
10. **标定迭代** **[重大]**：`4.09 px → 3.328 → 1.034 → 0.378 px`（30 组），基线约 63.7 mm。结论：停止追 RMS，转入卷尺实测。
11. **模式说明**：全场景 vs 仅识别物体只改最近/最远点来源；中心点不变。
12. **Android** **[重大]**：Flutter + Rust + Kotlin/UVC；小米 17 Pro（Android 17）调试版实机约 30 FPS / 识别约 10 FPS；标定 JSON 导出、Material 3 三页、许可与验证记录齐备。
13. **中断点**：最后要求的 commit/push + 签名 Release + 3D 模型上传，在会话侧未确认落地；远程当时无 Android 提交、无 Release。

## 模式差异（用户曾反馈“看不出区别”）

| 模式 | 最近/最远点来源 |
|------|----------------|
| 全场景可靠深度 | 整图 8×8 网格中位深度极值（墙、桌面等也可） |
| 仅识别物体 | YOLO 框中央 60% 区域中位距离极值 |
