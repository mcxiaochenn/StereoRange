# Android 开发验证记录

2026-09-19，本地开发工作区验证。以下性能数据来自基础开发期调试构建，v1.0.1 正式发布说明见 [发布记录](../docs/releases/v1.0.1.md)。结果只适用于本次软硬件组合，不代表所有 Android 13～17 设备或物理测距精度。

## 已通过

- Python：47 项测试，包括新增标定 JSON 导出及非法数值拒绝；桌面入口保留。
- Rust：8 项测试，覆盖深度公式、无效值、有效范围、中位数、网格抗单点噪声、框内统计、物体模式、EMA/超时、标定结构/单位/分辨率检查。
- Python/Rust：随机深度、等值深度、全无效深度 3 组对照，框距离及两种极值模式和中心点相符（容差 `rtol=1e-5, atol=1e-6`）。
- Flutter：7 项状态/界面测试，包括权限拒绝、断连清空、暂停/后台恢复、标定失败保留原值、横竖屏布局、视图切换、高 RMS 告警，以及 v1.0.1 新增的仓库跳转和浏览器错误提示。
- 手机实际界面：自动连接真实相机，模式切换、暂停后恢复、设备与设置页面导航通过。
- 手机相机链路：真实 USB RGBX 帧经 JNI 复制到 Rust，OpenCV 校正/SGBM 和 ONNX 推理并行工作。无标定时无距离、加载标定后测距、停止清空、重载、重新连接、结果流释放均通过。
- 16 KB 页模拟器：`getconf PAGE_SIZE` 为 16384，OpenCV/ONNX 演示及模型缺失后恢复两项原生集成测试通过。
- Flutter 静态检查：`No issues found`；APK ZIP 和所含原生库 ELF LOAD 段的 16 KB 对齐检查通过。

## 实机性能样本

小米 17 Pro（系统型号 25098PN5AC）、Android 17 / API 37；DECXIN Camera，640×240 横向拼接、每侧 320×240，请求 30 FPS。Flutter 为 Debug 测试入口，Rust 原生库为 Release 编译。

| 指标 | 结果 | 统计口径 |
|---|---|---|
| 处理输出 | 900 帧 / 30.002 s ≈ 30.00 FPS | 30 秒实际收到的结果数 |
| 采集 | 29.60 FPS | 结束时的最近间隔采样，非全程均值 |
| 识别 | 9.96 FPS | 结束时的最近推理完成间隔，非全程均值 |
| 处理延迟 | 12.75 ms | 最后一帧从到达 Rust 至深度预览生成，不含曝光/USB/屏幕显示 |

识别线程限制启动间隔至少 100 ms；最新一帧覆盖等待队列。上述数据为开发期统计口径，正式包端到端表现以实测压测为准。

## 已定位并修复的验证问题

- 识别限速最初额外叠加了推理耗时，约 7.3 FPS；改为限制启动间隔后达到约 10 FPS。
- Rust 结果发送器未释放导致 Dart 取消订阅等待；新增显式取消接口，实机退出测试通过。
- 重新加载资源重复初始化 FRB、旧相机回调干扰重连：增加一次初始化与连接实例检查。
- 中途一轮授权等待超时、一轮测试进程提前退出，未计作通过；之后同一测试完整重跑并通过。

## 验收结论

- **已知物距误差（卷尺）**：已完成。
- **连续运行压测与稳定性**：已完成。
- 结果适用于本次软硬件组合与当前标定；更换相机、镜头位置或分辨率后需重新标定并按现场条件复核。
- 公开 APK 不含个人标定，真实测距前须导入本机匹配的标定 JSON。
